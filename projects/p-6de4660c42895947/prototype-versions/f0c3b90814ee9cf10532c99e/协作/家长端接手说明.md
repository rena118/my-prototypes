# 家长端接手说明

> 本分支供伙伴在现有家长手机端原型基础上继续细化。`main` 保存项目负责人确认的当前版本；伙伴修改完成后先提交评审，未经确认不合并到 `main`。

## 分支与基线

- 工作分支：`partner/parent-polish`
- 基于 `main`：`24d13fb`
- 私有仓库：`ppzhang011-commits/parent-mobile-prototype`
- 当前稳定标签：`v1.0.0`，仅作为历史里程碑，不是本分支的基线。

## 产品边界

- 家长端定位为“有限代办＋孩子报告查看”。
- 家长可在后台权限允许时，为对应学生代申报社团、代报名社团，并查看孩子的社团报告。
- 家长不是社团业务主体，不因代办获得学生社长、成员或审核管理身份。
- 不把教师桌面端或学生桌面端直接缩小为家长手机端；保持移动端任务和交互独立设计。

## 可以继续处理

- 项目负责人明确指派的家长端页面、交互、视觉和演示数据细化。
- 在不改变已确认产品边界的前提下补充字段、状态、异常和验收说明。
- 与修改范围直接相关的构建配置和使用说明。

## 当前注意事项

- 当前仓库尚未包含 `.prototype/` 需求与标注资产。需要把家长端需求接入原型生成器时，先与项目负责人确认本轮页面和需求范围，再初始化并提交项目自己的 `.prototype/`，不能从教师端或学生端复制。
- 不直接向 `main` 推送，也不自行合并伙伴分支。
- 未经项目负责人明确授权，不发布、取消发布或修改远端 Pages 项目。
- 不提交 `node_modules/`、本机构建缓存、密钥或个人配置。

## 验收与回交

- 执行 `npm run build`，确认移动端原型可正常构建和打开。
- 回交时说明修改页面、交互变化、验证结果、遗留问题和提交编号。
- 如果本轮新增 `.prototype/`，同时核对页面登记、需求正文、标注和附件无断链。
- 由项目负责人评审后决定是否合入 `main`；需要长期维护另一产品版本时另建 `release/*`，不把伙伴分支当作永久版本线。
